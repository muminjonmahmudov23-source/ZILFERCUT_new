ZILFERCUT — ASOSIY MENU THEME'LARI
=====================================

Bu papka ilovaning HOME / ASOSIY MENU sahifasida ishlatiladigan fon rasmlari,
bannerlar va dekorativ elementlar uchun.

Rasmlarni aynan shu joyga joylang:
THEME/home-menu/

Tavsiya etiladigan fayllar:
- home-background.png — asosiy menyu fon rasmi
- home-banner.png — New Project tugmasi tepasidagi banner
- home-card-bg.png — My Projects kartalari foni
- home-glow.png — neon nur yoki dekorativ overlay

O'lcham va format:
- Telefon foni: 1080 x 1920 px (9:16).
- Banner: taxminan 1600 x 700 px.
- PNG yoki WebP ishlating.
- Matn va tugmalar ko'rinishini to'smaydigan rasm tanlang.

GitHub'ga qo'shish:
1. ZIP'ni oching.
2. THEME/home-menu/ papkasiga rasmlarni nusxalang.
3. GitHub repository'da shu papka yo'lini saqlang.
4. Commit qiling.

MUHIM: Hozir bu papka rasmlarni saqlash uchun tayyor. Starter ilova ularni hali
avtomatik ko'rsatmaydi. Keyingi kod bosqichida Theme Picker va Home Theme loader
funksiyalarini ulash kerak.
